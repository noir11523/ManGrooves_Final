# ManGROOVES 2.0.0+71 — Short photo warnings

Duplicate photo warnings now use two short messages: “Photo already used. Choose a new one.” for an earlier submission, and “Photo already added. Choose another.” for a duplicate in the current report. Long lists of photo names were removed from the alert on web, mobile web and Android. Photo validation and draft recovery remain the same.

Existing web and Android photo/report tests check the shorter messages and preserved draft behavior. The API, website bundle and Android download are released together.
